Overview

Abstract

World Action Models (WAMs) have emerged as an important paradigm in robot learning, jointly predicting future scene states and robot actions from current observations and instructions. However, future states entangle task-related changes with large amounts of task-irrelevant content, such as static backgrounds, which weakens the model's ability to capture changes relevant to task execution. To address this, we propose DiffWAM, a Mixture-of-Experts (MoE) framework that enhances world representations by jointly learning future-state prediction and consecutive visual difference prediction. We define consecutive visual differences as differences between the latent representations of consecutive observations, providing an explicit learning signal for temporal variation. The framework comprises a World Expert for future frame prediction, an Action Expert for action generation, and a Diff Expert for predicting these latent differences along the trajectory. A structured unidirectional attention mask conditions the Diff, World, and Action Experts solely on the current-frame representation while blocking attention between experts. This design allows both the World and Diff Experts to be removed during inference, introducing no additional inference overhead. DiffWAM achieves state-of-the-art performance on the LIBERO and RoboTwin 2.0 benchmarks and substantially improves over FastWAM on real-world manipulation tasks. Specifically, it attains average success rates of 98.8%, 92.65%, and 88.3%, outperforming the state-of-the-art baseline (i.e., FastWAM) by 1.75, 1.55, and 15.0 percentage points, respectively.

Method

Three experts, one shared observation.

The World and Diff Experts share early visual processing layers, then specialize in future-state generation and latent-difference regression. Structured attention prevents information leakage between prediction pathways.

Training & inference

Scale the optimization strategy with the data.

S

DiffWAM-S

Freezes the independent Latent Diff Block for smaller training sets while retaining visual difference supervision in the shared representation.

L

DiffWAM-L

First trains the independent Diff Expert, then jointly optimizes all modules for larger and more diverse datasets.

→

Same inference path

Both configurations deploy only the Observation Encoder and Action Expert, with no additional inference overhead.
